

# Data

This directory contains the datasets, schemas, and reference data used by the Supply Chain Data Engineering Platform.

## Structure

- `raw/` — Raw source data received from upstream systems.
- `sample/` — Synthetic datasets used for development and demonstration.
- `reference/` — Reference and lookup data.
- `schemas/` — Dataset schema definitions and data contracts.

Production data and sensitive information must never be committed to this repository.
