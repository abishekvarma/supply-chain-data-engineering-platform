# Data Model Documentation

This directory contains comprehensive documentation about the supply chain data platform's data model.

## Contents

- **data-dictionary.md** - Detailed descriptions of all entities, attributes, and their definitions
- **relationships.md** - Entity relationships, foreign keys, and cardinality
- **data-quality-rules.md** - Data validation rules and quality standards

## Overview

The supply chain data model includes entities for managing:
- Customers and their information
- Products and inventory
- Warehouses and distribution centers
- Vehicles and transportation fleet
- Drivers and personnel
- Orders and order management
- Shipments and shipment tracking
- Shipment events for real-time tracking

For detailed schema information, see the `data/schemas/` directory.
